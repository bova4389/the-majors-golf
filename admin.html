Finalize Tournament

Run this while scores are still live in Firestore (within a week of the tournament ending). It calculates final standings and outputs JavaScript you can paste directly into standings.js.

How to hardcode (do this right after a tournament ends):
  1. Select the completed tournament and click Generate Export
  2. Copy the output and paste it into standings.js, replacing the empty MAJOR_YYYY_TOTAL = [] lines
  3. Add the tournament to TOURNAMENT_REGISTRY at the top of standings.js with hardcoded: true
  4. Bump the ?v=YYYYMMDD version strings in index.html
  5. Commit and push — the site will use the hardcoded data forever and never hit ESPN again
